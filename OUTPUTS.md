# Outputs and relation to the manuscript

Every new run records the config, package versions, input hash, code hashes, status and validation audit. Failed or incomplete runs are not publication outputs. Empty OOF tables for an unrequested task are expected.

| Output from new runs | Meaning / related R2 material |
| --- | --- |
| `manifest.json`, `data_validation.json` | Reproducibility record; cohort, target inventory and label audit |
| `clinical_summary.csv`, `clinical_categories.csv` | Descriptive clinical variables; Table 1 |
| `PCR_panel_diversity_*.csv` | Detected targets, natural-log Shannon and Pielou; Table 1 |
| `species_comparisons.csv` | Four representations; two-sided Welch/Mann–Whitney, 16-taxon Bonferroni/BH, bootstrap effects; Supplementary Tables 1/3, Response A3 |
| `correlation_*.csv`, `cluster_*.csv`, `partial_correlations.csv` | Descriptive correlation, cutoff/normalization/bootstrap/hierarchical robustness; Figure 2, Supplementary Table 4, Response A2 |
| `adjusted_associations.csv` | Three taxa × four outcomes, four available clinical covariates; Supplementary Table 6 |
| `model_inventory.csv`, `panels.json` | Explicit candidate/selector family and panel rules |
| `classification_oof.csv`, `regression_oof.csv` | Actual held-out predictions per participant, repetition and model |
| `outer_splits.csv`, `fit_audit.csv`, `selected_features.csv`, `inner_grid_scores.csv` | Train/test membership, preprocessing, selected taxa and inner tuning audit |
| `classification_summary.csv`, `regression_summary.csv`, `repeat_metrics.csv` | Mean metrics across repetition-pooled test predictions; Table 2 and Supplementary Table 2 |
| `conditional_bootstrap.csv`, `paired_performance_deltas.csv` | Participant-block intervals and paired differences conditional on fixed OOF predictions; Supplementary Table 7A |
| `dummy_reference_deltas.csv` | Paired comparisons with train-prevalence/train-mean Dummy |
| `participant_average_oof.csv`, `regression_pairwise.csv`, `regression_friedman.csv` | Participant-level mean absolute errors across repeats; Holm family includes all 231 Linear pairs per gas; Supplementary Table 7B–D |

| Transformer parent `*_seed_results.csv`, `*_seed_summary.csv` | Actual new seed reruns; arithmetic mean and sample SD across training seeds; comparable in structure to Supplementary Table 8 |
| Final figures `figures/`, `analysis/` | Publication-design PNG/PDF/TIFF and data-derived checks; frozen reported performance, without predictive refitting |

Classification bootstrap preserves class counts and resamples participants with all their repeated predictions together. Paired models use the same participant draws. Main prediction metrics pool outer folds within each repeat before averaging repeats. Averaging a participant’s predictions first is a distinct diagnostic summary and is labeled separately. Error comparisons average absolute errors across repeats before paired testing, rather than taking the error of an averaged prediction.

Log1p gas sensitivities retain both transformed-scale R2 and inverse-transformed raw-ppb error measures. Conventional evaluation-set R2 and train-mean-reference skill are different measures. Original unrounded fitted predictions are required to recompute these measures; they cannot be reconstructed from a rounded manuscript table.

Frozen CSVs in `reference/tables/` preserve the current manuscript’s reported precision. They do not become new-model outputs when copied or plotted. Native Word formatting, figures embedded in Word and submission pagination remain in the separate final manuscript files.

Optional diagnostics for a new model run:

```text
python code/diagnostic_figures.py --results results/linear_main --output results/linear_diagnostics
python code/permutation_figures.py --help
```

These diagnostics use saved run data. The final manuscript design is generated by `python run.py figures` from the frozen R2 references.
